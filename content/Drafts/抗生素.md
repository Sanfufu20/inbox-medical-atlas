# 抗生素

---

## 1. 藥只攻擊五個地方

排序原則：這個標的和人類細胞有多不一樣。愈不一樣，藥愈安全。

| 標的 | 代表藥 | 人類有？ | 結果 |
|---|---|---|---|
| 細胞壁 | Penicillin · Cephalosporin · Carbapenem · Vancomycin | 沒有 | 治療窗最寬 → **主力** |
| 蛋白質合成 | Aminoglycoside · Tetracycline（30S）／Macrolide · Clindamycin · Linezolid（50S） | 核糖體不同（70S vs 80S） | 毒性來自「像細菌的那部分人體」 |
| 核酸 | Fluoroquinolone · Rifampin | 酵素構造不同 | 脫靶效應多 |
| 葉酸合成 | TMP-SMX | 不自己合成 | 但骨髓仍受影響 |
| 細胞膜 | Colistin · Daptomycin | 有膜 | 毒性最大 → **最後才用** |

- β-lactam 是主食，因為人類沒有細胞壁，可以大劑量長療程，主要風險是過敏而非毒性。
- Aminoglycoside 傷腎傷耳、Linezolid 久用骨髓抑制與視神經病變，都是同一件事：粒線體核糖體是 70S。
- Colistin 靠打穿細胞膜，而你也有膜。

## 2. 革蘭氏染色是一道牆

陽性菌外面只有厚肽聚醣，藥飄過去就碰到標的。陰性菌多包一層疏水外膜，藥只能從少數孔道（porin）鑽進去。這道牆解釋：

- **Vancomycin 對所有陰性菌無效**：分子量 1450，porin 只讓 600 以下通過。幾何學問題。
- **「廣效」是一部鑽孔史**：Penicillin G 太疏水鑽不進去；加胺基變 ampicillin 就有了陰性活性。之後每一代 cephalosporin 都在改側鏈，為了更好鑽、更不怕酵素。世代不是火力等級。
- **綠膿天生難搞**：外膜通透性只有大腸桿菌的百分之幾，porin 少又窄，還有外排幫浦。環境嚴苛的菌對藥也硬。
- **厭氧菌對 aminoglycoside 完全免疫**：這類藥要靠依賴氧氣的主動運輸才進得去。所以膿瘍裡無效。
- **Mycoplasma 對 β-lactam 無效**：沒有細胞壁 = 沒有標的。不是抗藥性。

## 3. 細菌只有三種抵抗方式

| 招 | 做法 | 代表 | 加 BLI 有用嗎 |
|---|---|---|:--:|
| 分解 | 分泌 β-lactamase 咬斷藥 | MSSA · H. influenzae | ✅ 這是主場 |
| 換鎖 | 改掉標的本身 | MRSA（PBP2a）· VRE（D-Ala-D-Lac） | ❌ |
| 關門抽水 | 減少 porin、增加外排 | 綠膿 · Acinetobacter | ❌ |

抑制劑本身幾乎不殺菌，只是替本體擋子彈。所以複方多出來的菌譜，是「本來打得到、之前被酵素攔下」的那些菌。

- Amoxicillin + clavulanate = **Augmentin**；Ampicillin + sulbactam = **Unasyn**；Piperacillin + tazobactam = **Tazocin**。
- 三者都多了 MSSA 與厭氧。Tazocin 額外有綠膿（來自本體 piperacillin，不是抑制劑）。
- Sulbactam 例外：對 Acinetobacter 有自己的直接殺菌力。
- **怎麼加 BLI 都殺不了 MRSA**，它換的是鎖。所以「用了 Tazocin 還在燒」要想 MRSA、黴菌、或有膿沒引流。
- Tienam 的 cilastatin 不是 BLI，是腎脫氫肽酶抑制劑，與菌譜無關。

## 4. 菌住哪裡，決定它造成什麼病

多數感染是自己的菌跑錯地方。所以「部位長什麼菌」= 「那裡平常住誰」，而住誰由環境決定。

| 部位 | 住著誰 | 造成 |
|---|---|---|
| 皮膚、鼻前庭（乾、鹹、營養少） | CoNS · S. aureus | 蜂窩組織炎、導管與植入物感染 |
| 鼻咽 | S. pneumoniae · H. influenzae · M. catarrhalis | 中耳炎、鼻竇炎、社區肺炎 |
| 口咽、牙齦溝（深處缺氧） | Viridans strep · 口腔厭氧 | 誤吸、肺膿瘍、亞急性心內膜炎 |
| 大腸（無氧，厭氧菌是好氧的千倍） | B. fragilis · E. coli · Klebsiella · Enterococcus | 腹腔、憩室炎、UTI、膽道、肝膿瘍 |
| 胃與小腸上段（胃酸） | 幾乎無菌 | 上消化道穿孔的感染遠輕於下消化道 |
| 醫院水槽、呼吸器管路 | Pseudomonas · Acinetobacter | VAP、燒燙傷、導管 |

「橫膈膜以上厭氧用一種藥、以下用另一種」不是規則——上面是口腔菌，下面是大腸菌，本來就是兩群生物。

## 5. 為什麼療程可以差二十倍

藥有效還要看細菌所在的環境。三件事會讓有效的藥失效：

- **細菌不在生長**：β-lactam 干擾細胞壁合成，但只有分裂中的細菌在合成細胞壁。膿瘍中心與生物膜裡的菌處於靜止期。
- **藥進不去**：膿瘍無血管，骨頭與瓣膜贅生物血流差。
- **局部環境失活**：膿瘍酸性缺氧，aminoglycoside 進不去也活性下降。

推論：

- **膿瘍必須引流**，不是比較快，是不引流抗生素物理上做不到。感染植入物要移除、導管菌血症要拔管。Source control 就是主要治療。
- **心內膜炎、骨髓炎四到六週**：滲透差、生長慢。
- 決定療程的不是菌，是它躲在哪。單純膀胱炎三天，心內膜炎六週。

給藥方式同理：β-lactam 是時間依賴（拉長輸注 > 拉高劑量，所以 Tazocin 對綠膿建議輸 3–4 小時）；aminoglycoside 與 FQ 是濃度依賴（所以一天一次大劑量）。

## 6. 經驗性用藥是決策

開藥當下你本來就不知道是什麼菌——這是問題的定義，不是你的缺口。培養要兩三天，敗血症每延遲一小時死亡率就上升。

判準不是「最可能是誰」，而是：**猜錯的代價多大？**

漏掉綠膿或 MRSA 病人可能死；多蓋的代價是副作用、抗藥性、C. diff、費用。兩種錯誤不對稱，不對稱程度取決於病人多重。所以病人愈重起始愈寬，愈穩定愈窄。

同一診斷在不同病人有不同起始，是風險權衡不同，不是標準不一致。廣效抗生素不是比較好的藥，是比較貴的保險——所以培養報告一出來、不確定消失了，就該降階把保險退掉。

實作上：設一個蓋鏈球菌與腸內桿菌的基本盤（Ceftriaxone），然後問三件事。

| 問題 | 什麼時候 yes | 加什麼 |
|---|---|---|
| 要蓋綠膿？ | 住院 >48h／近 90 天用過抗生素／結構性肺病／中性球低下／長期導管或呼吸器／燒燙傷 | 換 Cefepime · Pip-tazo · Meropenem |
| 要蓋 MRSA？ | 化膿性皮膚感染／導管／院內／休克／已知定殖／近期住院或洗腎 | 加 Vancomycin |
| 要蓋厭氧？ | 橫膈以上：誤吸膿瘍、牙源、頭頸深部　以下：腹腔、骨盆、糖尿病足 | 上：Amp-sulbactam／Clindamycin　下：加 Metronidazole |

肺炎多問一個：**非典型**。β-lactam 對 Mycoplasma／Chlamydophila／Legionella 無效，住院 CAP 用 Ceftriaxone + Azithromycin 或 Levofloxacin 單用。

## 7. 十二支藥

選它們是因為剛好填滿上面的格子。

| 藥 | 位置 | 空缺／地雷 |
|---|---|---|
| **Ampicillin** | 唯一好用的**腸球菌與 Listeria** 藥 | 對 penicillinase(+) MSSA 無效 |
| **Amp-sulbactam**（Unasyn）<br>**Amox-clav**（Augmentin） | 換來 MSSA + 全域厭氧 → 肺膿瘍、咬傷、糖尿病足 | 沒綠膿。Unasyn 額外有 Acinetobacter |
| **Cefazolin** | **確認 MSSA 後的首選**，比 Vancomycin 更有效 | 不過 BBB。側鏈與所有 penicillin 不同 → 青黴素過敏多半可用 |
| **Ceftriaxone** | 社區萬用基本盤，一天一次、過 BBB | **沒綠膿、沒腸球菌、沒厭氧**（後面所有升階的理由）。腦膜炎要 2g q12h |
| **Cefepime** | Ceftriaxone + 綠膿，且過 BBB | 腎功能差沒調量 → 腦病變、非痙攣性癲癇 |
| **Pip-tazo**（Tazocin） | 除 MRSA／非典型／ESBL 幾乎全包 | 不過 BBB。與 Vancomycin 併用增加 AKI |
| **Ertapenem** | 社區型 carbapenem，含 ESBL，一天一次 | 三個沒有：綠膿、腸球菌、Acinetobacter。不用於 CNS |
| **Meropenem** | 火力天花板，過 BBB | 仍無 MRSA、E. faecium、非典型 |
| **Vancomycin** | MRSA 代名詞，只殺陽性 | 口服不吸收（只治腸道 C. diff）。監測改 AUC/MIC 400–600。紅人症候群是組織胺反應，放慢輸注即可 |
| **Levofloxacin** | 口服吸收近 100% → 降階主力；蓋鏈球菌+非典型可單藥治 CAP | Cipro 治不了肺炎鏈球菌；Moxi 沒綠膿也不用於 UTI。QT、肌腱、主動脈剝離、C. diff |
| **Azithromycin** | 蓋非典型的配角；傷寒／志賀／彎曲桿菌首選 | 台灣肺炎鏈球菌抗藥率約 85% → **不可單用治 CAP** |
| **Metronidazole** | 純厭氧 + 原蟲，零好氧活性 | 肺膿瘍不能單用——不是蓋不到口腔厭氧，是蓋不到共病的微需氧鏈球菌。禁酒 |
| （**TMP-SMX**） | 四個獨門：PCP、Nocardia、Stenotrophomonas、青黴素過敏者的 Listeria | 台灣 E. coli 抗藥 5–7 成 → 不當經驗性用藥 |

台灣另外三支繞不開：**Ceftazidime**（唯一有綠膿的三代，但陽性活性差；Vibrio 與類鼻疽指定用藥）、**Doxycycline**（人畜共通症通用解）、**Clindamycin**（壞死性感染抑制毒素；但 C. diff 風險最高，B. fragilis 抗藥 3–5 成，橫膈以下別用）。

| MRSA | Vancomycin（肺炎可考慮 Linezolid） |
| 肺炎鏈球菌 | Penicillin 或 Ceftriaxone |
| Group A Strep | Penicillin（毒素症候群加 Clindamycin） |
| E. faecalis | Ampicillin |

| E. coli／Klebsiella 一般 | Ceftriaxone |

## 12. 容易踩到的

- 懷疑綠膿不要用 **Ceftriaxone／Ertapenem**。
- 腸球菌不要用任何 **cephalosporin**。
- 腎盂腎炎不要用 **Nitrofurantoin**（CrCl<30 也不適用）。
- MRSA 肺炎不要用 **Daptomycin**（被肺泡界面活性劑去活化）。
- 菌血症不要用 **Tigecycline**（血中濃度太低）。
- **C. diff 首選口服 Fidaxomicin**，次選口服 Vancomycin；Metronidazole 已退為替代。唯一該用 IV Metronidazole 的是猛爆性 C. diff（併口服 Vanco）。
- 用了 Pip-tazo／carbapenem **不必再加 Metronidazole**。
- **青黴素過敏看側鏈不是世代**：整體交叉 <2%。Cefazolin 側鏈與所有 penicillin 不同 → 多數可用。要避開的是側鏈相同：Amoxicillin↔Cefadroxil、Ampicillin↔Cephalexin。Aztreonam↔Ceftazidime 會交叉。
- **BLI 救不了 ESBL 與 AmpC**：ESBL 體外有效臨床不可靠 → carbapenem；AmpC 群（**E**nterobacter · **S**erratia · **C**itrobacter · **P**rovidencia · **M**organella）clavulanate 還會誘導 → Cefepime 或 carbapenem。

## 現在不必碰

Aminoglycoside 細節、Linezolid／Daptomycin、Colistin、Tigecycline、抗黴菌、抗病毒、抗結核、新一代複方 β-lactam。等真的照顧到那個病人再補。
