## 公開副本

- 不包含原 Vault 的設定、聊天紀錄、Git 歷史、帳號檔案或獨立題庫 HTML。
- 文字匯入掃描未發現明確的病歷號／姓名欄位、聯絡資料或金鑰。
- 移除一條本機絕對 URI，保留來源名稱。
- 圖片經縮圖目視檢查；一張含手環文字的圖片不附公開圖檔，只保留原來源連結。公開副本保留 190 張圖片。
- 來源與 metadata 格式調整記於 `data/import-manifest.json`；原 Vault 未修改。
